# MOTION — 全局动效规范（v0.16.0 起）

> 代码入口：`ui/motion/Motion.kt`（曲线/时长/按压缩放）+ `ui/components/RiseText.kt`（流式浮升）。
> 改任何动画先看这一份；新增界面沿用这里的时长与曲线，别自带一套。

## 1. 手感目标

Claude 的动效是「安静、快、不弹跳」：**位移小于你的预期，淡入承担主要观感，任何过渡都不许让用户等**。
量化的三条底线：

1. 单次过渡 **≤ 300ms**（超过就砍位移，不砍淡出）；
2. 位移不超过自身尺寸的 **1/5**（页面横向用页宽的 1/5、1/9）；
3. 只有「按下去」允许一点点过冲，其余一律不用弹簧。

## 2. 曲线与时长

| 名称 | 值 | 用途 |
|---|---|---|
| `Motion.Decel` | `cubic-bezier(0.16, 1, 0.3, 1)` | **进入**：起步快、尾巴长，像内容落定 |
| `Motion.Accel` | `cubic-bezier(0.4, 0, 1, 1)` | **退出**：不等、直接走 |
| `Motion.Standard` | `cubic-bezier(0.2, 0, 0, 1)` | 淡入淡出、颜色过渡 |
| `Motion.pressSpring()` | spring(0.45, 1400) | 按压回弹（唯一允许过冲的地方） |
| `Motion.ENTER_MS` | 300 | 页面/内容进入 |
| `Motion.EXIT_MS` | 220 | 退出（比进入短） |
| `Motion.SMALL_MS` | 220 | 展开/收起、列表项、卡片 |

## 3. 各处的落地

### 3.1 页面切换（`MainActivity`）

- 用 `AnimatedContent(targetState = Screen)` 包住整棵页面树。
- **只用 fade + 极轻微缩放**：进入 `fadeIn(150ms) + scaleIn(0.985→1, 300ms Decel)`，退出 `fadeOut(220ms) + scaleOut(1→1.012)`。
- ⚠️ **不要用 `slideIn/OutHorizontally`**：它走的是 layout（`Modifier.offset`），整页逐帧重新测量布局，
  第一次跑必掉帧（v0.16.0 就是这么做，被用户报「前几次动画卡」）。fade/scale 都在绘制阶段，
  整个过渡只改 graphicsLayer。
- 抽屉不属于页面树，切页时保持不动。

### 3.2 抽屉（`AppDrawer`）

**常驻组合**：抽屉面板不再用 `AnimatedVisibility` 反复拆装（首次打开要现场组合会话列表 + 解码头像，
就是「前几次卡、之后正常」的根因）。现在它是常驻的，只用 `offset` 位移 + 遮罩 `alpha`：
340ms 进（Decel）/ 260ms 出（Accel）。首次打开不再付组合成本。

### 3.3 底部面板与弹层

`ModalBottomSheet`（附件面板、模型面板）沿用 M3 自带滑动 + 遮罩，不自造。
**模型面板**：点心胶囊时**先自己收键盘再开面板**（`clearFocus + keyboard.hide` 与面板升起并行），
否则系统会在弹出窗口里把输入法掐掉，看起来像「先弹掉输入法、再唤起面板」，中间空一拍。
真实 `Dialog`（颜色模式、退出登录、重命名等）不加进场动画 —— Paparazzi 截图会拍到中间态，且系统窗口本身已有淡入。

### 3.4 列表

- 消息流、会话列表、Artifacts、项目列表、项目内会话：全部 `Modifier.animateItem()`
  → 插入淡入、删除淡出、排序平滑位移（Compose 默认 spring，无需手写）。
- 不给列表项做「依次错峰出现」：滚动时反复触发，观感廉价。

### 3.5 流式（`RiseText.kt`）

见文件头注释，参数照 `流式对话 · 浮升文字.html`：单字 1.5s `cubic-bezier(.2,.7,.2,1)`，
起始 `translateY(16dp)` + `blur(2.5dp)` + 透明 0 → 45% 时 0.9 → 100% 归位；
出字 40–65ms/字，逗号后 +85ms、句末 +210ms、段末 +325ms；
**「快速输出」开关**（功能页，默认关）：关 = 严格按上面这档固定速率；开 = 积压超过 8 个字时按比例提速
（最多落后网络约 1.5 秒）。**代码块不参与**：原样直出。

### 3.5.1 输入框展开（`Composer`）

键盘弹起时输入框变两行。**两态共用同一个 `BasicTextField`**（绝不复制输入框，否则光标与输入法连接重建），
展开/收起由**一个进度 `p`** 驱动（220ms，进 Decel / 出 Accel），任何时刻只有一个运动来源：

- 侧边「+ / 发送」宽度 `40dp × (1-p)` + 透明度 `1-p` + 缩放 `1-p`（宽度与透明度同步，看不到被压扁）；
- 底部动作行高度 `50dp × p`（内容 `requiredHeight(50dp)` 撑住不被压缩）+ 透明 `p` + 下移 `14dp × (1-p)`；
- 输入文字左边距 `8dp × p`：展开时 16dp 起，收起时随按钮宽度连续左移。
- 容器圆角 28dp（56dp 胶囊的半高）↔ 24dp 用 `animateDpAsState` 连续过渡。
- ⚠️ 不要用 `expandVertically/shrinkVertically` 做这一处：它在收起时会**裁剪**按钮，
  看起来像「高度先塌陷、按钮再消失」，用户明确否掉了。截图见 `composer_expanded_light`。

### 3.6 按钮与状态

- 圆按钮（输入栏 +、发送/停止、artifact 运行键）：按下缩到 **0.94×**（`Modifier.pressScale`，弹簧回弹）。
- 发送键 ↔ 停止键：淡入淡出 + 0.82× 缩放交叉切换（180–200ms）。
- 发送键可用/禁用：底色与图标色一起 `animateColorAsState` 180ms，不闪。
- 回复写完后的操作条（复制/重新生成）：淡入 + 上移 1/3 高度（300ms Decel）。

### 3.7 卡片展开

Artifact 卡片展开/收起：`expandVertically` + `fadeIn`，220ms Decel（流式时展开状态不被打回）。

## 4. 明确不做

- 页面之间的整页横推（超过 1/5 页宽的滑动）—— 太"安卓 2014"。
- 无限循环的装饰动画（首页星芒保持静态，只有登录页星芒是循环的）。
- 列表错峰入场、弹窗缩放弹出、按钮波纹（app 统一不用 ripple）。
