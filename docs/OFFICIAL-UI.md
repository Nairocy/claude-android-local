## 与当前实现的差异（值得改）

1. **对话页左上应是「← 返回」**，不是汉堡；汉堡只出现在首页 / 列表页 / 设置页。
2. 首页右上那个「幽灵」图标 = **无痕对话**（弹窗说明「无痕对话不会出现在您的历史记录和搜索中…」），**不是设置入口**。我们的版本目前点它进设置，语义不对；设置入口官方是抽屉底部头像。
3. 官方助手消息下有「Claude 是 AI，可能会出错。」免责声明；我们还没有。
4. 官方操作条 6 个图标；**用户拍板我们只要 4 个**，不补。
5. 官方列表项字号约 20sp、行高约 62dp，比我们当前的 17sp 更松。
